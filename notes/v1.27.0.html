What's New

  • Shortcuts and Spotlight can now drive Macterm directly: thirteen actions for creating projects and tabs, running commands, reading a pane, moving focus, and invoking a keybind. (#387)
  • A keybind can now be marked Global in Settings → Keymaps, so it fires even while another app is frontmost. (#385)
  • Right-clicking Macterm's Dock icon now offers New Window, New Tab, New Project… and Toggle Quick Terminal. (#381)
  • Finder's right-click menu now offers "New Macterm Project Here" on a folder. (#379)
  • Opening a folder with Macterm — from Finder's Open With, a drop on the Dock icon, or open -a Macterm <dir> — now creates a project for it. (#382)
  • The Dock icon now carries a badge counting the tabs whose bell you haven't looked at yet, when your ghostty config asks for bell-features = attention. (#384)
  • Macterm now uses the custom app icon your ghostty config already names through macos-icon and macos-custom-icon. (#383)
  • Setting macos-hidden = always in your ghostty config now runs Macterm without a Dock tile or menu bar, for working entirely out of the quick terminal. (#386)

Fixes

  • Confirmation alerts for closing a busy pane or tab now answer Return and Escape instead of needing the mouse. (#388)
  • The remaining confirmation alerts — unloading or removing a project, applying a layout, removing items or a layout file — now answer Return and Escape too. (#389)

Notes

  • While macos-hidden = always is on, Macterm has no menu bar, so Settings, Quit, About and Check for Updates have no route. Set your preferences before switching it on.
