What's New

  • A project's right-click menu in the sidebar now has a Worktrees submenu listing the repository's other git worktrees, and picking one opens a new tab of that project in the worktree. (#431)
  • macterm skills prints ready-made agent skills, so Claude Code, Codex and other coding agents can install them and learn to drive Macterm's panes, workspaces and subagents. (#432)
  • ⌃⌘F and ⌘↩ now toggle full screen, as they do in Ghostty.app. (#438)
  • A program that reports a failed run through its progress indicator now leaves a red dot on its tab instead of the green done dot. (#430)

Fixes

  • ⌘C, ⌘V and ghostty's other letter shortcuts now work under Ukrainian, Russian, Greek, Hebrew, Arabic and other non-Latin keyboard layouts. (#435)
  • Clicking or dragging to select text now lands on the row under the pointer after a trackpad scroll, on the alternate screen and at the top of scrollback, instead of one row off. (#439)
  • No project can be named Pinned any more, since such a project was unreachable by name from the CLI, and a folder called Pinned is added as "Pinned 2". (#436)
  • macterm project create --name now trims surrounding spaces and refuses an empty name. (#436)
  • macterm project create, project select and project rename print the project's real project:N instead of always project:1. (#434)
  • macterm project create --help no longer claims the command is idempotent. (#437)

Notes

  • ⌘↩ comes from ghostty's default keybindings; keybind = super+enter=unbind in your ghostty config turns it off.
  • The configuration docs now list the ghostty keys where Macterm's defaults differ from Ghostty's. (#428)

Thanks to @thdxg for this release.
