What's New

  • A project's right-click menu now lists its git worktrees, and picking one opens a new tab of that project in the worktree. (#431)
  • macterm skills prints ready-to-install agent skills so Claude Code, Codex and other coding agents can learn to drive Macterm themselves. (#432)
  • A program that reports a progress error now leaves a red "Failed" dot on its tab instead of the green done dot. (#430)

Fixes

  • ⌘C, ⌘V and ghostty's other letter shortcuts now work with Ukrainian, Russian, Greek, Hebrew, Arabic and other non-Latin keyboard layouts. (#435)
  • ⌃⌘F and ⌘↩ now toggle full screen, as they do in Ghostty.app. (#438)
  • With smooth scrolling on, clicking or dragging now selects the row under the pointer, including the partly visible row at the top of a pane and rows in the middle of a scroll animation. (#439, #443)
  • A second window showing the same tab no longer takes over the terminal's size when a program checks the keyboard mode. (#442)
  • A project can no longer be named Pinned, which made it unreachable by name from the CLI; a folder called Pinned becomes "Pinned 2", and project create --name trims padding and rejects an empty name. (#436)
  • macterm project create, select and rename now print the project's real project:N instead of always project:1, and project create --help no longer claims it is idempotent. (#434, #437)

Thanks to @thdxg for this release.
