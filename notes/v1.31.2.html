What's New

  • AI agents running in a remote project now show their logo, busy and done status, and their own tab titles in the sidebar, just like local ones. (#473, #480)
  • New installs open with a translucent, blurred window; if you never changed the opacity or blur sliders, you get the new look too. (#477)

Fixes

  • The window background no longer turns into a solid slab or keeps a stale tint after Helix changes its theme or quits. (#479)
  • A saved sudo password or key passphrase is now offered only to the real system program, never to a look-alike placed earlier on your PATH. (#468)

Notes

  • Settings → Appearance → Auto-name tabs is gone: a tab is always named after the program running in it, falling back to the shell or host name when nothing is. (#472)
  • Settings → Passwords: "Offer to save passwords" is now Enable password manager, a master switch that also turns autofill off, and "Ask for Touch ID" is now Require authentication. (#468)

Thanks to @thdxg and @timchesney for this release.
