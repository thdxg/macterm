What's New

  • Holding the Recent Tab shortcut now shows a strip of the project's tabs, each with a preview of its panes in their real split layout; the tab changes when the shortcut is released. (#346, #347)
  • Projects can carry a color that tints the project's sidebar icon and the icons of its tabs, set from the project's context menu or Settings → Projects. (#341)
  • A fresh install now opens with a project on your home directory and a pinned Welcome tab, each running a short tour you can read, scroll away, or run again with macterm tutor. (#339)
  • New tabs and new splits can each be set to open in the project directory or the active pane's directory. (#337)
  • Cmd+number now reaches tabs past 9: keep Command held and type more digits. (#326)
  • The hidden sidebar can peek as an overlay that leaves the terminal's size untouched, instead of pushing the panes aside. (#280)
  • Projects and tabs can be renamed by double-clicking their title in the sidebar. (#330, #333)
  • macterm tab rename, macterm project rename, and macterm project remove bring renaming and project removal to the command line. (#323, #327)
  • macterm pane run --no-submit leaves the text sitting on a pane's prompt instead of running it. (#328, #332)

Fixes

  • A slide or image filling most of a pane no longer repaints the whole window in its color when Adaptive background is on. (#335)
