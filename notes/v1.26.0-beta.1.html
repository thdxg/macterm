What's New

  • Macterm can open several windows, each on its own project: New Window on Cmd+N, Cmd+Shift+W to close one, and quitting and relaunching brings them all back on the projects they were showing. (#353, #359)
  • Selecting a tab another window already shows now gives you a live second view of it instead of a blank pane, and a window that isn't driving the shells says so — click it to work there. (#362, #366)
  • macterm pane mirror opens a second pane onto an existing pane's shell, so one session shows in two views; the view that isn't driving the size is dimmed until you click it. (#348, #349, #350, #352)
  • Each window keeps its own sidebar width and visibility, and its own adaptive terminal tint. (#356, #364)
  • New window commands: macterm window list, window close and window focus, plus --window on tab select and project select. (#359, #366)
  • A new app icon — a four-quadrant split-pane mark on a dark plate. (#363, #367)
  • Hovering a project row in the sidebar shows a plus button that opens a new tab in that project. It can be turned off in Settings → Appearance. (#331)
  • The terminal context menu now offers Jump to Top and Jump to Bottom, each disabled when you are already at that edge. (#338)
  • The sidebar starts at 220 points wide instead of 180, so ordinary project and tab names stop fading early. A width you have already set is left alone. (#357)

Fixes

  • A translucent window no longer looks more opaque when it loses focus. (#351)

Thanks to @thdxg and @nabilfreeman for this release.
