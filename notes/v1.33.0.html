What's New

  • Copy mode lets you move through the scrollback and select text from the keyboard: press ⌘⇧Space in a pane, and a cursor moves with Vim or Helix keys (choose in Settings → Keymaps → Copy Mode), with counts, search, a click that moves the cursor and page motions that scroll smoothly. (#608, #611, #613, #614, #615, #618, #624)
  • Explain Output asks Apple Intelligence on your Mac to explain a selection or the output of the last command in a popover, from the right-click menu, the command palette or ⌘⇧E, and nothing leaves the Mac. (#622)
  • Read-Only Mode stops all input to a pane, shows a Read-Only pill on it, and makes macterm pane run and pane key report that the pane refused the input. (#612)
  • Macterm is available in Korean and Simplified Chinese, and Settings → General → Language selects the app language. (#617, #619, #620)
  • A new Liquid Glass app icon, and on macOS 26 and later the Dock icon takes the colors of your terminal theme (Settings → Appearance → App Icon). (#628, #634, #638, #640, #644, #651, #652)
  • Files that open with Macterm by default now show a Macterm document icon in Finder. (#638, #645, #653)
  • Settings is a command in the command palette, and you can change its ⌘, keybind in Keymaps. (#649)
  • Each Ghostty config path in Settings → General is a link that opens the file in your editor. (#646)
  • Settings → Keymaps folds each category, and extension keybinds have their own group. (#625)
  • Each card in Settings → Extensions shows the screenshots of the extension before you install it. (#635)

Fixes

  • Ctrl+L at a prompt in a pane that is not full keeps the cleared screen in the scrollback again. (#610)

Notes

  • New defaults: the eyesclosed theme (#627), 12 pt window padding and the sidebar peek turned off (#641), and Snap to whole row turned on (#623). A setting that you changed keeps your value.
  • The adaptive Dock icon and Explain Output need macOS 26 or later. Explain Output also needs a Mac that supports Apple Intelligence, with Apple Intelligence turned on.
