What's New

  • The command palette's new Password Manager screen types any saved password into the focused pane, so prompts Macterm can't detect, such as sudo on a remote server, can still be filled, and passwords can now be added by hand. (#500, #502)
  • A new Worktrees palette screen lists the active project's git worktrees and opens a tab in the one you pick. (#505)
  • Searching the palette and Settings now ranks results the way fzf does and highlights the matched characters, and Settings → Keymaps can be searched by action, section or keybind. (#506, #508)
  • ⌘-clicking a path like src/main.rs:42 in a pane opens the file, and Macterm can be a text file's default app, opening it in your $VISUAL or $EDITOR in a new split or tab. (#484, #485)
  • Dragging a folder onto the sidebar opens it as a new project. (#489)
  • Right-clicking the toolbar lets you hide it or arrange the tab switcher, and View → Hide Toolbar toggles it. (#482)
  • Settings → Animations → Snap to whole row lets a trackpad scroll come to rest on a whole row instead of between rows. (#503)
  • The smooth cursor now animates the text under it as it glides, and the cursor trail no longer keeps the pane redrawing while it sits idle. (#490, #493)
  • Resizing a split from the keyboard now slides like a split does, and the split animation comes to rest without a tail of tiny resizes. (#494, #495)
  • Force click and ⌃⌘D look up the word under the pointer, ⌃-click opens the context menu, which now offers Copy for a selection, and ghostty's focus-follows-mouse is honored. (#491)
  • Settings sections now have a help button that opens their page in the docs. (#488)

Fixes

  • Each window now reopens at the size and position it was left at instead of the default size. (#498)
  • Clicking a link a program printed can no longer launch an app or executable: web and mail links open directly, other schemes ask first, and anything that could run code is blocked. (#483)
  • Right click works again in Helix and other crossterm programs after Macterm relaunches. (#492)
  • A new pane no longer sometimes shows a stray session "…" created line above its prompt. (#487)
  • A hovered link's underline and pointing hand no longer stick after the pointer leaves the pane, and programs and links follow the pointer in a window that isn't key. (#491)
  • Apply Layout's hints and errors now say "layout file", matching Save Layout. (#504)
  • Settings → Appearance's Peek style option now sits under its toggle and dims when peeking is off. (#501)

Notes

  • Settings → Passwords is now Settings → Password Manager. (#502)
  • Smooth cursor no longer overrides cursor-opacity, so your own value for that key applies again. (#490)

Thanks to @thdxg for this release.
