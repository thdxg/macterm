What's New

  • Right-clicking a folder in Finder offers Services → New Macterm Project Here, which adds it as a project and switches to it. (#379)
  • Folders open in Macterm as new projects — from Finder's Open With, a drop on the Dock icon, or the command line. (#382)
  • Right-clicking the Dock icon offers New Window, New Tab, New Project and Toggle Quick Terminal. (#381)
  • Any keybind can be marked global in Settings → Keymaps, so it fires while another app is frontmost. (#385)
  • A bell in a tab you aren't looking at badges the Dock icon with how many tabs are waiting, under bell-features = attention. (#384)
  • Macterm wears the custom app icon your ghostty config names, and follows it across a config reload. (#383)
  • macos-hidden runs Macterm with no Dock icon and no menu bar, for a quick-terminal-only setup. (#386)
  • Shortcuts and Spotlight can drive Macterm through thirteen new actions, from creating a project to reading what a pane is showing. (#387)

Notes

  • The first shortcut to reach Macterm asks whether to allow it. The answer lives in Settings → General.
  • Under macos-hidden there is no menu bar, so Settings, Quit and Check for Updates are reachable only by keybind or the macterm command.
