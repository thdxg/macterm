Macterm

A lightweight macOS terminal with vertical tabs, persistent sessions and a native interface.
Built on libghostty. Open source.

Get started GitHub ↗

Splits and navigation

Split a pane in any direction. Move between panes with a keybind. Drag a pane onto another pane to join them, or pull a pane out into its own tab.

Animations

Motion helps you keep your place. Scrolling slides, in scrollback and in full-screen programs such as Claude Code and Neovim. Splits grow into place. The cursor glides between positions and leaves a short trail, so you can find it after a jump. Each effect is a toggle in Settings → Animations.

Desktop widgets

Put a terminal on your desktop. It has the size and shape of a system widget and snaps into line next to the system widgets. It stays below your windows. Its shell keeps running when you quit, as in any other pane.

Sidebar and tabs

Projects and their tabs are in a native macOS sidebar. The sidebar is vertical, so there is room to read long names. The window takes the background color that the running program paints.

Tab switcher

Select a tab from a live preview of each tab. You choose the pane that you see, not a name.

Command palette and layouts

Press ⌘P to split panes, switch projects or open a folder. Declare the tabs, splits and commands of a project in ~/.config/macterm/projects/. Apply the layout and Macterm builds the tabs.

Custom palettes

Turn the output of any command into a screen of the command palette. A YAML file in ~/.config/macterm/palettes/ can list your commits, containers or Kubernetes pods. Search the list, select one item, and run a command on it in a split.

Open a folder from the Dock

Drop a folder on the Macterm Dock icon, or use Open With in Finder. Macterm opens the folder as a new project.

Quick terminal

A global terminal drops down from any app with a keybind. It goes away when you are done.

Remote projects

Open a folder on another machine over SSH. The panes keep running on the host. They keep running when you quit, when the connection drops and when you restart your Mac.

Password Manager

Type a password one time at an ssh, sudo or database prompt. Macterm then offers to save it in your keychain. The next time that prompt appears, a bubble offers to fill the password in after Touch ID.

  • Session persistence

    When you quit, your shells keep running. Start Macterm again. Every pane returns with its scrollback and its running programs.

  • Control CLI

    The bundled macterm command controls the running app over a socket. Scripts and AI agents can open panes and run commands.

  • Pinned tabs

    Pin a tab above your projects to keep it. It starts each time Macterm starts. If its session ends, Macterm starts it again with its command.

  • Ghostty compatibility

    Macterm reads your existing ghostty/config. Your theme, font and keybinds carry over.
