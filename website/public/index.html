Macterm is a lightweight macOS terminal with vertical tabs, persistent sessions and a native experience. Built on libghostty and open source.

Get started GitHub ↗

Splits and navigation

Split panes and move between them from the keyboard.

Animations

Scrolling, splits and the cursor glide into place.

Desktop widgets

Put a terminal on your desktop as a widget.

Sidebar and tabs

Your projects and their tabs are in a native sidebar.

Tab switcher

Select a tab from a live preview of each tab.

Command palette and layouts

Find any action in the palette, and save the tabs of a project as a layout.

Custom palettes

Turn the output of any command into a list that you can search.

Open a folder from the Dock

Drop a folder on the Dock icon to open it as a project.

Quick terminal

A terminal drops down over any app.

Remote projects

Panes on a remote host keep running when you quit.

Password Manager

Macterm saves the passwords that you type at a prompt and fills them in again.

  • Session persistence

  • Control CLI

  • Pinned tabs

    Keep a tab above your projects. It starts with Macterm.

  • Ghostty compatibility

    Macterm reads your Ghostty config.
