OVERVIEW: Send a single key press to a live pane.

Delivers one key press through the terminal's key-encoding path — the
counterpart to `pane run`, which pastes a whole command line. Use it for
control keys, named keys, and single printable keys a TUI reads as keystrokes
rather than as pasted text.

The chord grammar matches keybinds: modifiers ctrl/cmd/shift/opt joined with
'+', then one key token. Examples:

  macterm pane key ctrl+c          # interrupt the foreground process
  macterm pane key escape          # send Esc to a TUI
  macterm pane key up              # arrow key (mode-aware encoding)
  macterm pane key j               # a bare printable key (vim-style nav)
  macterm pane key shift+1         # the shifted character ('!')
  macterm pane key space           # space bar
  macterm pane key 'ctrl+\'        # SIGQUIT char (quote for the shell)
  macterm pane key enter           # submit (alias of 'return')

Option chords stay on the raw encoding path — their character is a
keyboard-layout translation this path can't resolve — so use `pane run` when
you need the literal text Option would compose.

With no pane/tab/session selector it targets the current pane via
$MACTERM_SESSION.

USAGE: macterm pane key <chord> [--project <project>] [--tab <tab>] [--pane <pane>] [--session <session>] [--socket <socket>] [--json]

ARGUMENTS:
  <chord>                 The key combination, for example a, space, ctrl+c,
                          escape, up or ctrl+\.

OPTIONS:
  --project <project>     Project scope (name, UUID, or index). The default is
                          the active project.
  --tab <tab>             Tab scope (title, UUID, or index).
  --pane <pane>           Target pane by UUID, or index within the tab (pane:2).
  --session <session>     Target pane by zmx session name (restart-stable).
  --socket <socket>       Control socket path. It overrides discovery.
  --json                  Print the raw JSON payload instead of a table.
  -h, --help              Show help information.
