OVERVIEW: List panes. The default is the active project.

USAGE: macterm pane list [--project <project>] [--tab <tab>] [--socket <socket>] [--json]

OPTIONS:
  --project <project>     Project to list (name, UUID, or index). The default
                          is the active project.
  --tab <tab>             Limit the list to one tab (title, UUID, or index).
  --socket <socket>       Control socket path. It overrides discovery.
  --json                  Print the raw JSON payload instead of a table.
  -h, --help              Show help information.
