OVERVIEW: Make a project active.

USAGE: macterm project select <project> [--window <window>] [--socket <socket>] [--json]

ARGUMENTS:
  <project>               Project name, UUID, or index.

OPTIONS:
  --window <window>       Window to select it in (index or id). The default is
                          the focused window.
  --socket <socket>       Control socket path. It overrides discovery.
  --json                  Print the raw JSON payload instead of a table.
  -h, --help              Show help information.
